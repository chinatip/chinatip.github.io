# chinatip.github.io

Personal site of Chinatip (Kate) Kultanapanit, served by GitHub Pages.

Plain HTML, CSS and JavaScript with no build step and no dependencies:

- `index.html`: content
- `styles.css`: design tokens, light/dark theme, layout
- `script.js`: theme toggle, card spotlight, copy-email button

To preview locally, open `index.html` in a browser. To deploy, push to `master`.
